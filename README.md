# Lumine Dental Studio

A premium dental clinic website built with Next.js 15, React 19, TypeScript, TailwindCSS, Framer Motion, Lucide Icons, React Hook Form, Zod, Embla Carousel, React CountUp, and `next/image`.

## Scripts

```bash
npm install
npm run dev
npm run build
npm run typecheck
```

## Notes

The project uses royalty-free Unsplash imagery through `next/image` remote optimization. Update `metadataBase` in `app/layout.tsx` before deploying to a production domain.
