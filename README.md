# Lumine Dental Studio

A modern, premium dental clinic website built with Next.js 15, React 19, and Tailwind CSS.

## Features

- Modern responsive UI
- Premium user experience
- Appointment booking
- Formspree integration
- SEO optimized
- Accessible design
- Smooth animations
- Reusable components

## Tech Stack

- Next.js 15
- React 19
- TypeScript
- Tailwind CSS
- Framer Motion
- shadcn/ui
- React Hook Form
- Zod
- Lucide React
- Formspree

## Getting Started

Clone the repository:

```bash
git clone https://github.com/abdeljalil-01/Dentist-Website.git
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open your browser:

```
http://localhost:3000
```
